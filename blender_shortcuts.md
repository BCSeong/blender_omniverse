# Blender Essential Shortcuts

## Viewport Navigation
| Shortcut | Action |
|----------|--------|
| `MMB drag` | Orbit |
| `Shift + MMB` | Pan |
| `Scroll` | Zoom |
| `Numpad 1/3/7` | Front / Right / Top view |
| `Ctrl + Numpad 1/3/7` | Back / Left / Bottom view |
| `Numpad 5` | Toggle perspective / orthographic |
| `Home` | Frame all |
| `Numpad .` | Frame selected |

## Camera
| Shortcut | Action |
|----------|--------|
| `Numpad 0` | Toggle camera view |
| `Ctrl + Numpad 0` | Set selected as active camera |
| `N` → View → Lock Camera to View | Move camera with mouse in camera view |

## Selection
| Shortcut | Action |
|----------|--------|
| `LMB` | Select |
| `Shift + LMB` | Add to selection |
| `A` | Select all |
| `Alt + A` | Deselect all |
| `B` | Box select |
| `H` | Hide selected |
| `Alt + H` | Unhide all |

## Transform
| Shortcut | Action |
|----------|--------|
| `G` | Grab (move) |
| `R` | Rotate |
| `S` | Scale |
| `G/R/S + X/Y/Z` | Constrain to axis |
| `G/R/S + Shift + X/Y/Z` | Exclude axis |

## Rendering
| Shortcut | Action |
|----------|--------|
| `F12` | Render image |
| `Ctrl + F12` | Render animation |
| `Esc` | Cancel render |
| `Z` | Shading mode pie menu |
| `Z → Rendered` | Real-time render preview in viewport |

## Object
| Shortcut | Action |
|----------|--------|
| `Ctrl + J` | Join selected objects |
| `M` | Move to collection |
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` | Redo |
| `Ctrl + S` | Save |
